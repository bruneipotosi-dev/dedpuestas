# Dedpuestas

Web de fans para predecir quién cae en **Dedsafio 4** apostando **Dedines**, una moneda virtual **sin valor real**: no se compran, no se venden y no se canjean.

> Proyecto de fans no oficial. Sin relación con los organizadores de la serie. Todos los derechos de la serie pertenecen a sus creadores.

## Qué hay aquí
| Carpeta | Contenido |
|---|---|
| `docs/` | Brief, requisitos, arquitectura y decisiones (ADR) |
| `design/` | Diseño aprobado y tokens |
| `data/` | Seed de jugadores y equipos |

## Stack
Next.js · TypeScript · PostgreSQL · Prisma · Docker Compose · GitHub Actions · Cloudflare Tunnel
